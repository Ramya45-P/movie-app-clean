# 🎬 Movie Recommendation System

## Project Overview

This is a Movie Recommendation System built using React for the frontend and FastAPI for the backend. Users can register, log in, browse movies, compare movies, manage favorites, receive recommendations, and view notifications.

## Features

- User Registration
- User Login (JWT Authentication)
- View Movies
- Add, Update and Delete Movies
- Movie Comparison
- Favorites
- Movie Recommendations
- Notifications

## Technologies Used

- React
- FastAPI
- SQLAlchemy
- SQLite
- JWT Authentication
- Vercel
- Render
