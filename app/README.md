# 🎬 Movie App Backend (FastAPI)

A full-stack Movie Management API built with **FastAPI**, **SQLAlchemy**, and **SQLite**.  
It supports authentication, movie CRUD, favorites, recommendations, and notifications.

---

## 🚀 Features

### 👤 Authentication
- User registration
- Login with JWT token
- Protected routes using Bearer token

### 🎬 Movies
- Create movie
- Get all movies
- Get single movie
- Update movie (single + bulk)
- Delete movie

### ❤️ Favorites
- Add favorite movies
- Get all favorites
- Delete favorite

### 🎯 Recommendations
- Smart recommendations based on favorite genres

### 🔔 Notifications
- View notifications
- Unread count
- Mark as read
- Auto notification for recommendations

---

## 🛠 Tech Stack

- FastAPI
- SQLAlchemy
- SQLite
- Pydantic
- JWT Authentication
